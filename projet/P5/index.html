NoteMD

NotesMD est votre solution complète pour une gestion de notes Markdown sans accroc, avec synchronisation en temps réel et organisation intelligente.

Fonctionnalités Clés

Édition Markdown Fluide

Un éditeur conçu pour les développeurs avec coloration syntaxique précise, raccourcis clavier intuitifs et rendu en temps réel instantané.

Cloud Sync

Vos notes sont sauvegardées automatiquement et accessibles partout, sur tous vos appareils.

Mode Sombre

Une interface reposante pour vos sessions de codage nocturnes, avec basculement instantané entre thème clair et sombre.

Exportation Facile

Exportez vos documents en PDF, HTML ou Markdown brut en un seul clic pour un partage rapide.

Défis & Solutions Techniques

Synchronisation temps réel multi-appareils

Mettre en place une synchronisation fiable entre l'application React Native et Supabase via Postgres Triggers, tout en gérant les conflits de modification simultanée et le mode hors-ligne.

Pipeline CI/CD mobile avec GitHub Actions

Automatiser le build, les tests et la publication de l'APK Android via GitHub Actions sans serveur dédié, en gérant la signature du keystore de façon sécurisée via les secrets GitHub et en produisant un artefact téléchargeable à chaque release.

Rendu Markdown performant en React Native

Afficher un rendu Markdown riche (titres, code, tableaux, listes) dans React Native sans WebView, en sélectionnant et adaptant les bonnes bibliothèques pour garantir des performances natives et une expérience d'édition sans latence perceptible.
