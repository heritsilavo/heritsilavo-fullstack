MyMovieApp

Une application web permettant d'afficher une liste des films récents et leurs genres, en s'appuyant sur l'API de TheMovieDatabase. Ce projet a été réalisé en suivant la formation Next.js sur Dyma.fr.

Voir l'applicationVoir la formation dans Dyma.fr

Tech Stack

Next.js
React
TheMovieDatabase API
internationalisation i18n

Fonctionnalités Clés

Films, Séries & Catégories

Explorez un catalogue complet de films et séries organisé par genres grâce aux données en temps réel de TheMovieDatabase.

Recherche par intervalle de date

Filtrez les contenus par plage de dates de sortie pour trouver exactement ce que vous cherchez.

Films récents

Découvrez automatiquement les dernières sorties cinéma et séries mises à jour en continu via l'API TMDB.

Internationalisation i18n

Interface disponible en plusieurs langues pour une expérience utilisateur adaptée à chaque région.

Défis & Solutions Techniques

Gestion du cache et des requêtes API Next.js

Optimiser les appels à l'API TMDB avec les mécanismes de cache de Next.js (ISR, SSR) pour garantir des données fraîches sans surcharger les quotas de l'API.

Internationalisation des contenus dynamiques

Gérer l'i18n non seulement sur les libellés statiques de l'interface, mais aussi sur les données retournées par l'API TMDB (titres, descriptions, genres) dont la langue varie selon les paramètres de la requête.
